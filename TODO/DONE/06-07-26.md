### StateTree BP + Level
  - Idle/Roam → [Tick + HasTarget] → Agro
  - Idle/Roam → [Tick + HearingCondition] → Investigate
  - Investigate → [OnCompleted + HasTarget] → Agro
  - Investigate → [OnCompleted + !HasTarget] → Idle
  - Agro → [Tick + Dst(≤AttackRange)] → Attack
  - Agro → [Tick + Dst(≤ChaseRange, >AttackRange)] → Chase
  - Agro → [Tick + !HasTarget] → LostTarget
  - Chase → [Tick + Dst(≤AttackRange)] → Attack
  - Chase → [Tick + !HasTarget] → LostTarget
  - Attack → [Tick + FleeCondition] → Flee
  - Attack → [Tick + !HasTarget] → LostTarget
  - Flee → [OnCompleted] → Idle
  - LostTarget → [OnCompleted] → Idle
  - LostTarget → [Tick + HasTarget] → Agro
