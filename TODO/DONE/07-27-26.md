# ✅ Sprint A5c — Auth Extraction & Login Server

**Completed:** 2026-07-27  
**Duration:** ~1 day (compressed — reused existing foundation)

## Deliverables

### A5c.1 — Auth Subsystem Extraction
- `UOnsetAuthSubsystem` (world subsystem, DS-only via `ShouldCreateSubsystem`)
- `HandlePostLogin` — delegates from GameMode, resolves platform ID, auto-creates account
- `HandleLogout` — cleanup on disconnect
- `ValidateAuthTicket` — validates Steam auth ticket, clears timeout
- `AuthMode=Direct` config key (default, preserves existing behavior)
- `AOnsetGameModeBase::PostLogin` slimmed to delegate + UI push
- `AOnsetGameModeBase::Logout` override added
- `Server_SendAuthTicket` routes through subsystem

### A5c.2 — Session Token System
- `FOnsetSessionToken` struct (PlatformID, Platform, ExpiryUnix, Signature)
- `GenerateToken` — HMAC-SHA256 signed token: `Base64(payload).Base64(signature)`
- `ValidateToken` — split, decode, verify HMAC, check expiry
- HMAC-SHA256 implemented manually via `FGenericPlatformMisc::GetSHA256Signature`
- Config: `AuthTokenSecret`, `AuthTokenLifetimeSeconds` (default 300s)
- `Client_SessionToken` / `Client_SessionTokenFailed` RPCs

### A5c.3 — Login Server
- `AOnsetLoginServerGameMode` — auth → token → kick (2s delay)
- `Scripts/RunLoginServer.ps1` — launch script with editor fallback
- Config sections `[OnsetLoginServer]`, `[Onset.GameServer]`
- Reuses `Onset.exe` (no separate target — Server target unsupported by distribution)

### A5c.4 — Game Server Token Validation
- `PreLogin` override — extracts `?Token` from URL options
- `PreLoginTokenAuth` — validates token, caches in `PendingTokenAuthMap`
- `HandlePostLogin` — checks pending map for platform info (skips UniqueId extraction)
- Works with both `Direct` and `Token` auth modes

## Decisions
- HMAC-SHA256 instead of JWT (zero external deps)
- No separate LoginServer target (Server target unsupported; uses Onset.exe + map override)
- `PendingTokenAuthMap` bridges `PreLogin` → `PostLogin` (address-keyed)
- `AuthMode=Direct` unchanged; `Token` mode gated behind config
