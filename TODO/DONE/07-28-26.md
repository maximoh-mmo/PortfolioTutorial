## Deliverables

### Custom SHA256 Implementation
- Created `Source/Onset/Private/Crypto/SHA256.h` + `SHA256.cpp`
- Pure-software SHA256 — no platform dependency, no `FGenericPlatformMisc` assertion
- Replaced all `FGenericPlatformMisc::GetSHA256Signature` calls with `FSHA256::GetSHA256Signature`

### Fixed Config Reading — `GEngineIni` + Command-Line Override
- `UOnsetAuthSubsystem::Initialize` now reads `[Onset.Auth]` from `GEngineIni` (was `GGameIni`)
- Added `-AuthMode=` command-line override (used by `Test_All.ps1`)
- Changed `if (GConfig->GetString(...))` wrapping to direct `GConfig->GetString(...)` + separate validation

### Fixed Token Address Lookup
- Strips port from `GetPlayerNetworkAddress()` in `HandlePostLogin` before matching `PendingTokenAuthMap`

### Fixed Client Travel URLs
- `steam://` prefix → direct `IP:Port/Path?Token=` format in both `Client_TravelToGameServer` and `ReconnectToGameServer`
- Unlike old `steam://` URLs which only work with Steam, direct IP URLs work with `-NOSTEAM`

### Config File Lookup Fix
- `Server_SelectCharacter` and `ReconnectToGameServer`: changed `GGameIni` → `GEngineIni` for `GameServerIP`/`GameServerPort`
- Config values are in `DefaultEngine.ini` under `[Onset.Auth]`, which maps to `GEngineIni`

### Fixed GameServerPort
- `DefaultEngine.ini`: `GameServerPort=7777` → `7778` to match `Test_All.ps1` game server port

### Fixed Empty PlatformID (Direct Mode, No Steam)
- `HandlePostLogin`: when `UniqueId.IsValid()` returns true but `ToString()` is empty, fall back to `DEV_<client_IP>`
- Changed `else` to separate `if (PlatformID.IsEmpty())` so fallback runs regardless of `UniqueId` validity state

### Fixed Login Server Kick Timer
- Moved kick timer inside `if (AuthMode == Token)` block in `OnsetLoginServerGameMode::PostLogin`
- In Direct mode, the player stays connected until character select triggers travel — the kick was destroying the connection after 2 seconds

### Test Script Overhaul
- Renamed `Scripts/Test_All.ps1` → `Test_All.ps1` (root level)
- Added `-NOSTEAM` to all three processes (prevents `incompatible_unique_net_id` rejection when Steam DS API fails)
- Added interactive loop: `[Enter]` launches additional clients, `[Q]` quits and cleans up all processes
- All client logs captured to `Saved/Logs/Client_N.log`
- Cleanup kills all tracked processes in `finally` block
