# 🗓 WED 8 JUL — CommonUI Screen Stack Migration (A5b.5)

## Summary
Replaced all canvas-based HUDs (`AOnsetLobbyHUD`, `AOnsetMenuHUD`) and old UMG widgets (`UMainMenuWidget`, `UCharacterSelectWidget`) with a proper CommonUI screen stack framework. Resolves the "UMG doesn't render in packaged -game builds" issue permanently.

## CommonUI Framework (8 files)
- [x] `UOnsetActivatableWidgetStack` with `EOnsetUILayer` (Game, Menu, Modal)
- [x] `UOnsetRootLayout` — 3 BindWidget stacks + `GetStackForLayer()`
- [x] `UOnsetScreenBase` — inherits `UCommonActivatableWidget`, activation/deactivation hooks, input config
- [x] `UOnsetButtonBase` — hover/click sound support
- [x] `UOnsetGameViewportClient` — inherits `UCommonGameViewportClient` (fixes CommonUI input routing)
- [x] `UOnsetUISubsystem` — `GameInstanceSubsystem`, owns RootLayout, `PushScreen()`/`PopScreen()`
- [x] `UOnsetGameInstance` — clean `Init()` with no early widget creation
- [x] `WBP_RootLayout` Blueprint with 3 named stacks matching BindWidget
