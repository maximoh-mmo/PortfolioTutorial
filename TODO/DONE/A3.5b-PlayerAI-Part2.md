## Deviations from Plan
- **Combined EngageTask** — not separate MoveToTask + AttackTask; movement and attack live in one task for simpler state management
- **No UPlayerAIStateTreeComponent** — uses `UStateTreeAIComponent` (same as NPCs)
- **No navpath-cost loop** — uses `ProjectPointToNavigation` + distance sort instead of `GetPathCost` (simpler, less GC pressure)
- **Gameplay tags** — `TAG_Ability_Attack` tags filter which abilities the AI can activate (HitReaction, buffs excluded)
- **bIsAlive flag** — `IsAlive()` filters candidates; pool-returned NPCs (`bIsAlive = false`) never selected
