## 4. Create Input Actions
- [ ] `IA_Move` (Input Action, Value Type: Axis2D) — virtual joystick, WASD, L-Stick
- [ ] `IA_Cursor` (Input Action, Value Type: Axis2D) — gamepad R-Stick cursor emulation
- [ ] `IA_Confirm` (Input Action, Value Type: Digital (Bool)) — tap, left-click, R-Stick click, A button
- [ ] `IA_Target` (Input Action, Value Type: Digital (Bool)) — right-click, virtual button, gamepad bumper
- [ ] `IA_Ability1-4` (Input Actions, Value Type: Digital (Bool)) — number keys, virtual buttons, face buttons
- [ ] `IA_PvPToggle` (Input Action, Value Type: Digital (Bool)) — P key, virtual button, D-pad down

## 5. Create Input Mapping Contexts
- [ ] `IMC_Touch` — virtual joystick + tap + virtual ability buttons
- [ ] `IMC_Desktop` — mouse clicks + WASD + number keys
- [ ] `IMC_Gamepad` — L-Stick movement + R-Stick cursor + button abilities
