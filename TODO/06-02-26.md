## Design
- Static library `UAbilityTargetingLibrary` + `FAbilityTargetData` struct
- No component, no PlayerController changes — abilities call the library directly
- `GetTargetData(TargetingComponent, SourceActor)` returns actor, location, direction from current target
- `FAbilityTargetData` stripped: no Radius (set per-ability), no PlayerPawn-typed fields (generic SourceActor)
